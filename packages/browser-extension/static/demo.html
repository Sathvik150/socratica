Try it live

Check any text

Paste an answer from ChatGPT, Claude or anywhere else. Socratica finds each checkable claim, searches for evidence and marks it supported, contradicted or unverifiable, quoting the source behind every verdict.

Only short searches built from each claim are sent, never your text: to Socratica's search relay (Google results via Serper), Wikipedia, Wikidata and DuckDuckGo. The judge here is the offline one, which runs in your browser and misses paraphrases; the extension can use an AI model instead.

Built on a simple idea

Question More. Trust Better.

Socratica is inspired by Socrates and the belief that better questions lead to better answers. It brings transparency and evidence to every AI response: each claim is marked supported, contradicted or unverifiable, and missing evidence is never treated as proof of an error.

How it works

Four steps, every answer

  1. Extract claimsEach checkable factual sentence becomes a claim.
  2. Search for evidenceA web search engine and the sources you choose.
  3. Judge with quotesEvery verdict must quote its source word for word.
  4. AnnotateClaims are underlined in place, with the evidence a click away.

    Download

    Get Socratica

    Chrome extension

    Checks ChatGPT answers in place as they finish, with the evidence a click away.

    Download for Chrome
    1. Unzip the download.
    2. Open chrome://extensions, turn on Developer mode, click Load unpacked and pick the unzipped folder.
    3. Accept the privacy notice on the settings page that opens. Nothing is checked or sent before you do.
    4. Use chatgpt.com as usual. Web search works with no key.

    Agent Skill

    For Claude, Claude Code and other Agent Skills hosts.

    Download the skill
    1. Claude: with code execution on, Settings, Skills, Upload skill, and choose the zip.
    2. Claude Code: unzip socratica-skill-*.zip -d ~/.claude/skills/

    Without scripts: instruction-only skill.

    ChatGPT plugin

    The same skill, packaged for ChatGPT's plugin uploader.

    Download the plugin
    1. Keep the zip zipped.
    2. Open Plugins, New Plugin, upload it and choose Add plugin.

    Without scripts: instruction-only plugin.

    Command line

    One file for Node 20 or later, with your own documents, a local model or an API key.

    Download the CLI
    1. Unzip it and open the socratica-cli folder.
    2. node socratica.mjs verify --answer answer.txt --web socratica
